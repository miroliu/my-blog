# Hugo 网站更新说明

## 更新流程

1. **文件修改后不会自动生效**：
   Hugo是静态网站生成器，当您修改了内容文件或配置文件后，需要重新生成网站才能看到更新。

2. **生成网站的命令**：
   ```bash
   hugo --gc
   ```
   这个命令会清理缓存并重新生成整个网站。

3. **开发服务器模式**：
   如果您在本地开发，可以使用开发服务器模式，它会实时监控文件变化并自动更新：
   ```bash
   hugo server -D
   ```

4. **关于目录结构**：
   我们已经将三级目录结构改为二级目录结构，所有运维相关文章现在都在正确的位置。

5. **验证更新**：
   运行生成命令后，可以在`public`目录中查看生成的静态文件，或者通过浏览器访问本地服务器来验证更新是否成功。

如果您使用的是自动部署流程，可能还需要将更改推送到版本控制系统（如Git），然后等待CI/CD流程完成部署。
