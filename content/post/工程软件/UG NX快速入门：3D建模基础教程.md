# UG NX快速入门：3D建模基础教程

## 引言

UG NX（Unigraphics NX）是西门子公司开发的一款功能强大的计算机辅助设计（CAD）、计算机辅助制造（CAM）和计算机辅助工程（CAE）软件。它广泛应用于航空航天、汽车、机械、电子等行业的产品设计和制造。本教程将帮助初学者快速掌握UG NX的基本操作，为进一步学习打下基础。

## 第一章：软件安装与配置

### 系统要求

- **操作系统**：Windows 10/11 64位
- **处理器**：Intel Core i5或更高配置
- **内存**：至少8GB RAM，推荐16GB以上
- **硬盘空间**：至少50GB可用空间
- **显卡**：支持OpenGL 4.5的独立显卡
- **分辨率**：1920x1080或更高

### 安装步骤

1. **准备安装包**：从西门子官方网站或授权经销商获取UG NX安装包

2. **解压安装文件**：右键点击安装包，选择"解压到当前文件夹"

3. **运行安装程序**：双击setup.exe文件开始安装

4. **选择安装语言**：通常选择"简体中文"

5. **接受许可协议**：阅读并接受软件许可协议

6. **选择安装组件**：
   - 核心组件（必须安装）
   - CAD/CAM/CAE模块（根据需求选择）
   - 文档和教程（建议安装）

7. **选择安装路径**：注意路径中不要包含中文字符

8. **配置许可证服务器**：输入许可证服务器信息或选择单机许可

9. **开始安装**：点击"安装"按钮，等待安装完成

10. **完成安装**：安装完成后重启计算机

### 初次启动配置

1. **启动UG NX**：双击桌面快捷方式或从开始菜单启动

2. **设置用户界面语言**：如果首次启动，会提示选择界面语言

3. **配置许可证**：根据提示配置许可证信息

4. **设置工作目录**：选择一个文件夹作为默认工作目录

## 第二章：用户界面介绍

### 主界面布局

UG NX的用户界面主要包括以下部分：

1. **菜单栏**：位于界面顶部，包含所有命令菜单
2. **快速访问工具栏**：位于菜单栏上方，包含常用命令按钮
3. **功能区（Ribbon）**：位于菜单栏下方，包含各种功能选项卡
4. **资源条**：位于界面左侧，包含部件导航器、装配导航器等
5. **图形区**：位于界面中央，显示和编辑模型的主要区域
6. **提示栏**：位于图形区下方，显示操作提示和状态信息
7. **状态栏**：位于界面底部，显示坐标、选择信息等
8. **导航器**：用于模型浏览和选择

### 常用工具栏介绍

1. **标准工具栏**：新建、打开、保存、打印等基本操作
2. **视图工具栏**：旋转、缩放、平移等视图操作
3. **建模工具栏**：拉伸、旋转、扫描等建模操作
4. **草图工具栏**：直线、圆、矩形等草图绘制工具

### 工作环境设置

1. **自定义界面**：
   - 右键点击工具栏空白处，选择"自定义"
   - 可以添加或移除工具栏和按钮
   - 可以调整工具栏位置

2. **设置工作目录**：
   - 点击"文件" > "实用工具" > "用户默认设置"
   - 在左侧树状结构中选择"基本环境" > "工作目录"
   - 设置默认工作目录

3. **设置背景颜色**：
   - 点击"首选项" > "可视化"
   - 在"颜色"选项卡中设置背景颜色

## 第三章：基本操作技巧

### 视图操作

1. **旋转视图**：
   - 鼠标操作：按住MB2（中键）拖动
   - 快捷键：F7
   - 工具栏：点击"旋转"按钮

2. **缩放视图**：
   - 鼠标操作：MB2 + MB3（中键+右键）拖动，或滚动鼠标滚轮
   - 快捷键：F6
   - 工具栏：点击"缩放"按钮

3. **平移视图**：
   - 鼠标操作：MB2 + MB1（中键+左键）拖动
   - 快捷键：F5
   - 工具栏：点击"平移"按钮

4. **适合窗口**：
   - 鼠标操作：双击MB2（中键）
   - 快捷键：F8
   - 工具栏：点击"适合窗口"按钮

5. **定向视图**：
   - 快捷键：Ctrl+1（前视图）、Ctrl+2（俯视图）、Ctrl+3（右视图）
   - 工具栏：点击"前视图"、"俯视图"等按钮

### 对象选择

1. **选择对象**：
   - 单击MB1（左键）选择单个对象
   - 按住Shift键单击选择多个对象
   - 拖动MB1创建选择框选择多个对象

2. **选择过滤器**：
   - 在状态栏选择过滤器中设置过滤条件
   - 可以按类型（曲线、面、体等）过滤选择

3. **快速选择**：
   - 点击"编辑" > "选择" > "按类型选择"
   - 使用"类选择器"对话框进行精确选择

### 文件操作

1. **新建文件**：
   - 快捷键：Ctrl+N
   - 点击"文件" > "新建"
   - 在对话框中选择模板类型（模型、图纸、仿真等）

2. **打开文件**：
   - 快捷键：Ctrl+O
   - 点击"文件" > "打开"
   - 支持的文件格式：.prt（UG原生格式）、.igs、.step、.x_t等

3. **保存文件**：
   - 快捷键：Ctrl+S
   - 点击"文件" > "保存"
   - 建议定期保存，避免意外丢失数据

4. **另存为**：
   - 点击"文件" > "另存为"
   - 可以选择不同的文件格式

## 第四章：草图绘制基础

### 进入草图环境

1. **创建新草图**：
   - 在建模环境中，点击"主页"选项卡 > "草图"
   - 选择一个平面作为草图平面
   - 可以选择基准平面或实体表面

2. **草图平面选择**：
   - 使用现有平面：选择XY、YZ或XZ基准平面
   - 创建新平面：点击"平面"按钮，选择平面类型
   - 使用实体表面：直接选择实体表面

3. **草图设置**：
   - 进入草图后，可以设置网格显示、捕捉等
   - 点击"首选项" > "草图"进行详细设置

### 基本图元绘制

1. **直线**：
   - 点击"直线"按钮或使用快捷键L
   - 指定起点和终点
   - 可以设置角度和长度约束

2. **矩形**：
   - 点击"矩形"按钮
   - 指定对角点创建矩形
   - 可以创建中心点矩形、三点矩形等

3. **圆**：
   - 点击"圆"按钮或使用快捷键C
   - 指定圆心和半径
   - 可以通过三点、相切等方式创建

4. **圆弧**：
   - 点击"圆弧"按钮
   - 可以通过中心点和端点、三点、相切等方式创建

5. **多边形**：
   - 点击"多边形"按钮
   - 设置边数，指定中心点和半径
   - 可以创建内接或外切多边形

6. **曲线**：
   - 点击"艺术样条"或"样条曲线"按钮
   - 通过指定点创建平滑曲线

### 草图编辑

1. **移动对象**：
   - 选择对象，点击"移动"按钮
   - 指定移动方向和距离

2. **复制对象**：
   - 选择对象，点击"复制"按钮
   - 指定复制位置或数量

3. **镜像对象**：
   - 选择要镜像的对象
   - 点击"镜像"按钮
   - 选择镜像中心线

4. **修剪/延伸**：
   - 点击"快速修剪"或"快速延伸"按钮
   - 选择要修剪或延伸的曲线

5. **阵列**：
   - 选择对象，点击"阵列"按钮
   - 选择矩形阵列或圆形阵列
   - 设置阵列参数

### 尺寸标注

1. **线性尺寸**：
   - 点击"尺寸" > "快速"按钮
   - 选择要标注的线或两点
   - 拖动到合适位置并点击

2. **角度尺寸**：
   - 点击"尺寸" > "角度"按钮
   - 选择两条线
   - 拖动到合适位置并点击

3. **半径/直径尺寸**：
   - 点击"尺寸" > "半径"或"直径"按钮
   - 选择圆或圆弧
   - 拖动到合适位置并点击

4. **编辑尺寸**：
   - 双击尺寸值
   - 在弹出的对话框中修改数值
   - 点击"确定"应用更改

### 约束设置

1. **几何约束**：
   - 点击"约束"按钮
   - 可以添加重合、平行、垂直、相切等约束

2. **尺寸约束**：
   - 标注尺寸时自动添加尺寸约束
   - 可以通过约束对话框添加

3. **约束显示**：
   - 点击"首选项" > "草图"
   - 在"约束"选项卡中设置约束显示方式

4. **过约束处理**：
   - 当草图出现过约束时，系统会提示
   - 可以删除多余的约束或修改现有约束

### 退出草图

1. **完成草图**：
   - 点击"完成"按钮
   - 或使用快捷键Ctrl+Q
   - 返回建模环境

2. **取消草图**：
   - 点击"取消"按钮
   - 或使用快捷键Ctrl+Z
   - 放弃当前草图的修改

## 第五章：实体建模基础

### 基本体素特征

1. **块体**：
   - 点击"主页"选项卡 > "特征"组 > "块体"
   - 设置长度、宽度和高度
   - 选择放置位置

2. **圆柱体**：
   - 点击"主页"选项卡 > "特征"组 > "圆柱体"
   - 设置直径和高度
   - 选择放置平面和方向

3. **圆锥体**：
   - 点击"主页"选项卡 > "特征"组 > "圆锥体"
   - 设置底部直径、顶部直径和高度
   - 选择放置平面和方向

4. **球体**：
   - 点击"主页"选项卡 > "特征"组 > "球体"
   - 设置直径
   - 选择放置位置

### 基于草图的特征

1. **拉伸**：
   - 创建并完成一个闭合草图
   - 点击"主页"选项卡 > "特征"组 > "拉伸"
   - 选择草图曲线
   - 设置拉伸方向和距离
   - 可以设置偏置、布尔运算等选项

2. **旋转**：
   - 创建一个闭合草图和一条中心线
   - 点击"主页"选项卡 > "特征"组 > "旋转"
   - 选择草图曲线和旋转轴
   - 设置旋转角度
   - 可以设置布尔运算选项

3. **扫描**：
   - 创建一个轮廓草图和一条路径草图
   - 点击"主页"选项卡 > "特征"组 > "扫描"
   - 选择轮廓曲线和路径曲线
   - 设置对齐方式和缩放选项

4. **放样**：
   - 创建两个或多个截面草图
   - 点击"主页"选项卡 > "特征"组 > "放样"
   - 按顺序选择截面曲线
   - 设置过渡方式和约束条件

### 特征操作

1. **倒圆角**：
   - 点击"主页"选项卡 > "特征"组 > "倒圆角"
   - 选择要倒圆角的边
   - 设置圆角半径
   - 可以设置可变半径

2. **倒角**：
   - 点击"主页"选项卡 > "特征"组 > "倒角"
   - 选择要倒角的边
   - 设置倒角距离和角度

3. **抽壳**：
   - 点击"主页"选项卡 > "特征"组 > "抽壳"
   - 选择要移除的面
   - 设置壳厚度
   - 可以设置不同面的厚度

4. **布尔运算**：
   - 并集：点击"主页"选项卡 > "特征"组 > "合并"
   - 差集：点击"主页"选项卡 > "特征"组 > "求差"
   - 交集：点击"主页"选项卡 > "特征"组 > "相交"

### 特征编辑

1. **编辑特征参数**：
   - 选择要编辑的特征
   - 右键点击，选择"编辑参数"
   - 在弹出的对话框中修改参数

2. **移动特征**：
   - 选择要移动的特征
   - 右键点击，选择"特征操作" > "移动"
   - 设置移动方向和距离

3. **抑制/取消抑制特征**：
   - 在部件导航器中选择特征
   - 右键点击，选择"抑制"或"取消抑制"

4. **删除特征**：
   - 选择要删除的特征
   - 按Delete键或右键点击选择"删除"

## 第六章：实战案例 - 创建简单零件

### 案例：创建一个六角螺母

#### 步骤1：创建新文件

1. 点击"文件" > "新建"
2. 选择"模型"模板
3. 输入文件名"Hex_Nut.prt"
4. 点击"确定"

#### 步骤2：创建基本形状

1. 点击"主页"选项卡 > "特征"组 > "圆柱体"
2. 设置直径为20mm，高度为12mm
3. 点击"确定"

#### 步骤3：创建六边形

1. 点击"主页"选项卡 > "草图"
2. 选择圆柱体的上表面作为草图平面
3. 点击"主页"选项卡 > "草图"组 > "多边形"
4. 设置边数为6，大小为17mm（外切圆直径）
5. 确保多边形与圆柱体同心
6. 点击"完成"退出草图

#### 步骤4：拉伸切除

1. 点击"主页"选项卡 > "特征"组 > "拉伸"
2. 选择六边形草图
3. 设置拉伸方向为向下
4. 设置拉伸距离为12mm
5. 在布尔下拉菜单中选择"求差"
6. 点击"确定"

#### 步骤5：创建中心孔

1. 点击"主页"选项卡 > "草图"
2. 选择圆柱体的上表面作为草图平面
3. 点击"主页"选项卡 > "草图"组 > "圆"
4. 绘制一个直径为10mm的圆，确保与圆柱体同心
5. 点击"完成"退出草图
6. 点击"主页"选项卡 > "特征"组 > "拉伸"
7. 选择圆草图
8. 设置拉伸方向为向下，距离为12mm
9. 在布尔下拉菜单中选择"求差"
10. 点击"确定"

#### 步骤6：添加倒圆角

1. 点击"主页"选项卡 > "特征"组 > "倒圆角"
2. 选择螺母的上端面和下端面的所有棱边
3. 设置圆角半径为1mm
4. 点击"确定"

#### 步骤7：保存文件

1. 点击"文件" > "保存"
2. 确认保存路径和文件名
3. 点击"确定"
